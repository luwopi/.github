# luwopi

Three builders. Fond of NixOS, and of technology in general.

This is where we share the software we enjoy building. Sometimes because it is
useful, often because we can, and always because we want to use it ourselves.

## What you will find here

Repositories with flake-shaped experiments, tools we run every day, and the
occasional thing that started as "let's see if this works".

## Get involved

Ideas, questions or a bug? Open an issue in the repo it belongs to.
